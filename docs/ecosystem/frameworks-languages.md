# Frameworks and programming languages

A programming language defines syntax and semantics for expressing behavior. A framework is a structured set of libraries and conventions that helps build a category of software. TypeScript is a language layer; React is a UI library; Next.js is an application framework built around React. These are related but not interchangeable.

Framework choice affects routing, rendering, build conventions, and extension points. Language choice affects how developers express logic and what checks can be performed before runtime. See [the Next.js, React, and TypeScript relationship](../technology/next-react-typescript.md).
