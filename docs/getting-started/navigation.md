# How to navigate this wiki

Use the expandable sidebar to move by subject area. The top-level tabs group the manual into major domains; nested entries are individual articles. Breadcrumbs show where the current article sits. Use the search control to find tools, commands, concepts, or error terms across built pages.

Each article has a table of contents generated from its headings. Follow inline links to related concepts, or use the previous/next links at the bottom. Search is generated into the static site and runs client-side; it does not send queries to a hosted service.

## Reading implementation status

Treat **General concept** content as explanations of how a tool usually works. Treat **Pending source verification** content as an outline or documented intent until checked against the private repository tag. A **Planned** page is a placeholder. Never use a draft PR as evidence of released functionality.

For implementation questions, start with [Developer Platform overview](platform-overview.md), then inspect [architecture verification status](../architecture/overview.md). For practical work, use the [first application tutorial](first-application.md).
