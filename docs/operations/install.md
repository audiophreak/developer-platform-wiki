# Installation problems

**Planned.** Check Python >=3.12, uv availability, Git >=2.27, and project-local environment activation. For private template access, configure a Git credential helper such as `gh auth setup-git`; the devkit intentionally disables terminal prompts and cannot ask for credentials interactively.
