# Recovery and rollback

**Planned.** Before an upgrade, require a clean Git tree and create a recoverable commit. Review Copier conflicts and preserve `.copier-answers.yml`. Roll back by reverting the upgrade commit or restoring a known-good branch; never force-reset a working tree with uncommitted user data.
