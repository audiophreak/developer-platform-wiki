# Glossary

| Term | Meaning |
|---|---|
| **API** | Application programming interface: a defined way for software components to request behavior or data. |
| **Branch** | A movable Git reference used to isolate work. |
| **Build** | Transforming source and dependencies into output that can run or deploy. |
| **CI** | Continuous integration: automation that checks proposed or integrated changes. |
| **CLI** | Command-line interface; here, `devkit` is the platform CLI. |
| **Copier** | Template engine that renders and updates projects, including merge-based updates. |
| **Dependency** | A package or tool that a project consumes. |
| **Generated application** | A new app rendered from a template; it has its own Git history and can diverge. |
| **Git** | Distributed version-control system that records project history as commits. |
| **GitHub** | Hosted Git collaboration service with pull requests, permissions, and Actions. |
| **Lockfile** | File recording a concrete dependency resolution for repeatable installation. |
| **MVP** | Minimum viable product: the smallest useful product slice that tests a core need. |
| **npm** | JavaScript package manager and script runner. |
| **Node.js** | JavaScript runtime used by Next.js and the generated app toolchain. |
| **Package manager** | Tool that resolves, installs, and records software dependencies. |
| **Pull request (PR)** | A proposal to review and integrate one branch into another. |
| **React** | UI library for composing interfaces from components. |
| **Runtime** | Environment that executes a program. |
| **Static type checking** | Analysis of type relationships before execution; not a substitute for runtime validation. |
| **Template** | Reusable project source rendered with choices to create an application. |
| **TypeScript** | JavaScript-based language with static type syntax, transformed for execution. |
| **uv** | Python package and project manager used by the platform. |
| **Validation** | Checking that code or data satisfies rules, at build time or runtime. |

See the [ecosystem overview](../ecosystem/overview.md) and [Next.js/React/TypeScript relationship](../technology/next-react-typescript.md).
