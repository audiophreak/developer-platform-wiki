# Tailwind CSS

**Verified in Web Core v0.1.0:** Tailwind CSS v4 is used with `@tailwindcss/turbopack` pinned to 4.3.5. Tailwind's utility classes are composed in the app source; its build integration processes styles as part of the Next.js build. The starter's `globals.css` is the place to inspect theme variables and global styles. Avoid assuming Tailwind v3 configuration conventions apply to v4.

Tailwind addresses fast, consistent styling in markup and CSS with a utility vocabulary. Alternatives include CSS Modules and other CSS-in-JS or utility frameworks; tradeoffs concern authoring style, runtime behavior, design-system governance, and build integration.

Reference: [Tailwind CSS documentation](https://tailwindcss.com/docs). See [Next.js, React, and TypeScript](next-react-typescript.md).
