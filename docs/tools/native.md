# Native iOS toolchain

## Xcode (26 or newer) and xcodebuild

| | |
|---|---|
| **Problem** | Building, testing and running a SwiftUI app. |
| **Why selected** | Required for iOS. The project targets iOS 17.0 (`@Observable`, `NavigationStack`, `ContentUnavailableView`) and Swift 6 with complete strict concurrency. |
| **Invoked by** | `ios/scripts/test.sh`, `check-release-config.sh`, `e2e.mjs`, the native template's `xcode` tests and CI (macos-26 runner, newest installed Xcode 26), you (`open ios/App.xcodeproj`). |
| **Consumes** | `ios/App.xcodeproj` (static, generated by `tools/gen_pbxproj.py`), `ios/Config/*.xcconfig`, `Info-Debug.plist` / `Info-Release.plist`, `Package.resolved`. |
| **Produces** | `ios/.derived-data/` build products, `.xcresult` bundles. |
| **Phase** | Development, CI, release. |
| **Caveats** | Run `sudo xcodebuild -runFirstLaunch` after installing or updating Xcode. No team or signing material is committed; the simulator needs none. `doctor` only warns below 26. The acceptance workstation runs Xcode 27.2. |

## iOS Simulator and simctl

| | |
|---|---|
| **Problem** | Running the app and its hosted tests without a device or signing. |
| **Invoked by** | `scripts/simulator.sh` (selects a UDID), `test.sh direct` (`simctl boot`, `bootstatus`, `spawn`), CI (`simctl boot`). |
| **Caveats** | Runtimes are installed separately from Xcode (Xcode › Settings › Components). The hosted Keychain tests need a booted, healthy simulator. |

## Swift 6 and Swift Package Manager

| | |
|---|---|
| **Problem** | Keep everything that is not UI in a testable package, with exact dependency versions. |
| **Why selected** | `Packages/AppCore` builds and tests on the Mac host (`swift test`) as well as the simulator; SwiftPM's `exact:` pins and committed `Package.resolved` make builds reproducible. |
| **Invoked by** | Xcode (local package reference), `swift test`, `generate-client.sh` (`swift run --package-path Tools/Generator`). |
| **Phase** | Development, CI. |
| **Caveats** | Every dependency obeys the two-week rule, including transitive ones (`swift-collections` pinned to 1.7.5 because 1.7.6 was too new). |

## Swift OpenAPI Generator 1.14.3

| | |
|---|---|
| **Problem** | A typed Swift client that cannot drift from the server's API. |
| **Why selected** | Apple's generator; produces `Types` and `Client` from OpenAPI 3.1 with idiomatic naming, and pairs with an official runtime and URLSession transport. |
| **Invoked by** | `ios/scripts/generate-client.sh` only (never during a normal build; no build-tool plugin). |
| **Consumes / produces** | `ios/Contract/openapi.json` + `openapi-generator-config.yaml` → `Packages/AppCore/Sources/APIClient/*.swift` (committed). |
| **Depended on by** | `AppCore` (`APIService`, `ItemsModel`). |
| **Phase** | Development (generation), CI (zero-diff regeneration). |
| **Caveats** | Its dependency tree (OpenAPIKit 6.4.0, swift-argument-parser 1.8.2, Yams 6.2.2, swift-algorithms, swift-numerics) is a developer tool, never linked into the app. 1.14.4 was newer than the cutoff, so 1.14.3 is used. |

## swift-openapi-runtime 1.13.4, swift-openapi-urlsession 1.4.0, swift-http-types 1.8.0

The runtime the generated client needs, the URLSession transport, and the HTTP types the `BearerAuthMiddleware` uses. **Phase:** runtime (linked into the app).

## Security framework (Keychain)

| | |
|---|---|
| **Problem** | Storing the session token as a credential between launches. |
| **Why selected** | The platform's secure storage. `KeychainTokenStore` uses a generic-password item with `kSecAttrAccessibleWhenUnlockedThisDeviceOnly` and `kSecAttrSynchronizable = false`. |
| **Phase** | Runtime. |
| **Caveats** | Keychain calls need an app context with a Keychain entitlement: in an unhosted test process they fail with `-34018` (`errSecMissingEntitlement`). That is why those tests live in the app's hosted test target. |

## Swift Testing

Tests use the `Testing` framework (`@Suite`, `@Test`, `#expect`), run by `swift test` and `xcodebuild test`. Counts at the baseline: 58 package tests, 11 hosted app tests.
